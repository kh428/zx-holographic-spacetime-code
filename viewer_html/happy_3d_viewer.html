The HaPPY pentagon code in 3D (static code — no foliation, no gauge fixing)

Rendered with the open-source pyzx 3D viewer (github.com/kh428/pyzx_3d_viewer) — companion demo to arXiv:2601.04467 (QPL 2026). Green = Z spiders, blue dashed = Hadamard edges; boundary (physical) legs lie in the disk plane and every bulk (logical) leg is a free input rising out of it. Pauli webs are drawn on the wires, colours R/G/B = X/Z/Y. Drag to orbit, scroll to zoom. Requires internet once (three.js via import map).
